# Moldes de vinculación léxica

Dos derivados de semantic-molds que habilitan referencias de expresiones y llamadas directas. `brace_bindings` usa llaves y `keyword_bindings` usa palabras delimitadoras. Son subconjuntos didácticos; no implementan lenguajes de producción completos.

Gramática 4, grafo 5, versión 0.1.0. Los moldes estructurales anteriores permanecen intactos. El bloque `expression_bindings` configura destinos de referencia, clases de declaraciones directamente invocables, transparencia de grupos del callee y operadores unarios mutadores. Cada paquete incluye un ejemplo `calls`.

Ver [contrato y límites](../../docs/semantic-understanding/bindings.md).
