# Development Scripts

Scripts are development tools, not production server entry points.

- `scripts/validation/` checks schemas, language neutrality, lexical boundaries, and expression contracts.
- `scripts/benchmarks/` runs corpus, retrieval, and MCP performance measurements.
- `scripts/mcp/` verifies MCP protocol behavior and enrichment fixtures.

Run scripts from the repository root and read their command help before using them against non-synthetic data.
