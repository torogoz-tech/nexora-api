# Known Limitations

- Language understanding is profile-driven and partial for many languages.
- Types, complete control flow, aliases, re-exports, and deep call semantics are not universally available.
- MCP and remote provider behavior depends on deployment configuration and authorization.
- Cooperative filesystem and process limits are not a substitute for hostile-process isolation.
- Provider simulations and local fixtures do not certify external accounts or production deployments.

The project preserves evidence and uncertainty instead of inventing relationships or treating missing data as compliance.
